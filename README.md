# Everyday Wonder — The Puddle That Keeps the Sky

## What this is

An entry for the make.fun bounty "Everyday Wonder, Two Days to Find the
Line". The bounty asks for a single sentence, at most 200 characters,
that makes a small everyday moment strange and new. This entry takes
one concrete image — a puddle on an ordinary street after rain — and
turns it around: the puddle is not reflecting the sky, it is the one
place the sky comes down to rest.

## The entry sentence

> The puddle on my street isn't reflecting the sky — it's the one place
> the sky comes down to rest.

That is 97 characters, one sentence, grounded in a real moment.

## How to run

```sh
python3 main.py
```

The program writes the sentence to `/output/entry.txt` (or to
`$OUTPUT_DIR/entry.txt` when that variable is set). It checks the
sentence is within the 200-character limit first and fails loudly if
it is not.
